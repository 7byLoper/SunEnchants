# SunEnchants

Кастомные зачарования для серверов Minecraft на Paper и Spigot. Плагин добавляет 36 собственных зачарований, которые встраиваются в ванильную систему: они попадают в предметы через стол зачарования и наковальню, отображаются в лоре и работают на версиях от 1.16.5 до 1.21.x.

Автор: **Loper** · Telegram: [t.me/gloomdev](https://t.me/gloomdev)

## Возможности

- **36 зачарований** для оружия, брони, инструментов, луков и трезубцев.
- **Поддержка 1.16.5 – 1.21.x** через два модуля (legacy и modern) с общим API — плагин сам определяет версию сервера при запуске.
- **Гибкая настройка каждого чара** в отдельном YAML-файле: уровни, шансы срабатывания, шансы выпадения в столе зачарования, звуки и эффекты.
- **Whitelist зачарований** — включайте и отключайте чары одной строкой в `enchants.yml`.
- **Лимиты** на количество и сочетания зачарований (`limits.yml`).
- **Полностью настраиваемые сообщения** (`messages.yml`) с поддержкой MiniMessage и цветовых кодов.
- **Интеграция с PlaceholderAPI** и рядом плагинов экосистемы Sun.
- **Миграция старого лора** при переходе с legacy-версий на современные.

## Требования

| | |
|---|---|
| Ядро сервера | Paper / Spigot 1.16.5 – 1.21.x |
| Java | 17+ |
| Обязательная зависимость | [SunCore](https://t.me/gloomdev) |

### Необязательные зависимости

`PlaceholderAPI`, `WorldGuard`, `WorldEdit`, `SunGrindStone`, `SunMobMoney`, `SunHolyBossEvent`, `SunAutoMine`, `AntiRelog` — подключаются автоматически, если установлены.

## Установка

1. Скачайте `SunEnchants.jar` из раздела [Releases](https://github.com/7byLoper/SunEnchants/releases).
2. Установите обязательную зависимость **SunCore**.
3. Положите оба файла в папку `plugins/`.
4. Перезапустите сервер.
5. Настройте зачарования в папке `plugins/SunEnchants/`.

## Команды и права

| Команда | Право | Описание |
|---|---|---|
| `/senchants enchant <чар> <уровень>` | `senchants.command.enchant` | Наложить зачарование на предмет в руке |
| `/senchants givebook <чар> <уровень> [игрок]` | `senchants.command.givebook` | Выдать зачарованную книгу |
| `/senchants reload` | `senchants.command.reload` | Перезагрузить конфигурацию |
| `/setfilter` | — | Настроить фильтр для чара «Фильтр» |

Доступ к базовой команде даёт право `senchants.command.use`.

## Настройка

Структура конфигурации:

```
plugins/SunEnchants/
├── enchants.yml        # whitelist активных чаров и настройки миграции
├── limits.yml          # лимиты на зачарования
├── messages.yml        # все сообщения плагина
└── enchants/           # по одному файлу на каждый чар
    ├── poison.yml
    ├── bulldozer.yml
    └── ...
```

Пример настройки чара (`enchants/poison.yml`):

```yaml
enable: true
type: potion_effect
display_name: "&7Яд {level}"
max_level: 3
target:
  - IRON_SWORD
  - DIAMOND_SWORD
  - NETHERITE_SWORD
levels:
  1:
    chances:
      table_enchant: 6   # шанс выпасть в столе зачарования
      work: 12           # шанс срабатывания
    effects:
      - "POISON:0:60"
```

Чтобы отключить зачарование, уберите его ID из списка в `enchants.yml` или поставьте `enable: false` в его файле.

## Сборка из исходников

Проект собирается через Gradle и разбит на модули:

- `sunenchants-api` — общий API и контракты зачарований;
- `sunenchants-legacy` — реализация для 1.16.5;
- `sunenchants-modern` — реализация для 1.21.x;
- `sunenchants-plugin` — точка входа, команды, слушатели и конфигурация.

```bash
./gradlew clean build
```

Готовый `SunEnchants.jar` появится в `sunenchants-plugin/build/libs/`.

## Статистика

Плагин использует [bStats](https://bstats.org) для сбора анонимной статистики использования. Отключить сбор можно в `plugins/bStats/config.yml`.
